## หน้าแรกและการเลือกชุดคำถาม (v3.7)

ลำดับบนหน้า: โลโก้ mindfull → "เช็กอินใจ · ใช้เวลาประมาณ 2 นาที" → หัวข้อบรรทัดเดียว "วันนี้ใจคุณเป็นแบบไหน?" → คำอธิบายสั้น → แบนเนอร์คำแนะนำ "เลือกชุดคำถามให้ตรงกับชีวิตช่วงนี้" → "คุณอยู่ในช่วงไหน?" → การ์ดเลือก 2 ใบ (วัยทำงาน, นักเรียน / นักศึกษา) แต่ละใบมีภาพรวมตัวละครของชุดนั้นเป็นแบนเนอร์ มีป้ายหัวข้อย่อยบนภาพ (เรื่องงาน · เดดไลน์ · หัวหน้า · เวลาพัก / เรื่องเรียน · สอบ · เกรด · งานกลุ่ม) ชื่อกลุ่ม รายละเอียดสั้นๆ ("สำหรับคนที่กำลังทำงาน สถานการณ์มาจากชีวิตในที่ทำงานและหลังเลิกงาน" / "สำหรับคนที่กำลังเรียน สถานการณ์มาจากชีวิตในห้องเรียนและเวลาหลังเลิกเรียน") และปุ่ม "เริ่มเช็กใจเลย" → ข้อความท้ายหน้า "ไม่ต้องสมัคร · ไม่เก็บคำตอบ · ไม่ใช่การวินิจฉัย" และลิงก์สายด่วน 1323 ตัวละครปรากฏบนหน้าแรกเฉพาะในแบนเนอร์ของการ์ด

การกดปุ่มในการ์ดคือการเริ่มเล่น จึงไม่เพิ่มขั้นตอนและไม่กระทบงบเวลา 2 นาที ชุดที่เลือกกำหนดภาพประกอบ ชุดคำถาม (ข้อ 1–5 และข้อ 6) และ copy ของผลลัพธ์ ส่วนการคิดคะแนน กติกา 2 สัปดาห์ และ next step ใช้ร่วมกัน การ์ดเรียงแนวตั้งบนมือถือ และเรียงข้างกันเมื่อจอกว้างตั้งแต่ 720px

โฟลเดอร์รูป: `assets/work/` และ `assets/student/` แต่ละโฟลเดอร์มี `scenes/` (`q1`–`q6.jpg`, `sentnoti.jpg` หน้าสุดท้าย) และ `characters/` (`cumulo`, `nimbo`, `strato`, `humi`, `all` ภาพรวมที่ใช้เป็นแบนเนอร์การ์ดหน้าแรก) ส่วนโลโก้อยู่ใน `assets/logo/`

## หน้าคำถาม–คำตอบ (v3.8)

ข้อความคำถาม ตัวเลือก ลำดับ การสุ่ม และพฤติกรรมการตอบไม่เปลี่ยน ปรับเฉพาะหน้าตา ลำดับบนหน้า: ภาพสถานการณ์เต็มความกว้างบนสุด (วัยทำงานใช้ `assets/work/scenes/`, นักเรียน / นักศึกษาใช้ `assets/student/scenes/`) โดยแผ่นเนื้อหาสีขาวซ้อนขึ้นมาทับขอบล่างของภาพ → ปุ่ม "กลับหน้าแรก" (ข้อแรก) หรือ "ข้อก่อนหน้า" ทางซ้าย และป้ายกลุ่มทางขวา → "คำถามที่ n / 6" พร้อมแถบความคืบหน้า (ใช้กับทุกข้อรวมข้อ 6) → คำถาม ชิดซ้าย (ข้อ 1–5 มีบรรทัด "ช่วงนี้ ถ้าเจอแบบนี้ คุณน่าจะ…" ใต้คำถาม) → การ์ดคำตอบแตะได้ทั้งใบ มีวงกลมสถานะอยู่ด้านหน้าข้อความเต็ม (เลือกแล้วขอบ พื้น และวงกลมเปลี่ยนสี มีเครื่องหมายถูก) แล้วไปข้อต่อไปเอง → ท้ายหน้ามีโลโก้เล็กและ "เป็นแค่การเช็กความรู้สึก ไม่ใช่การวินิจฉัยนะ" ไม่มีป้ายลำดับ "สถานการณ์ที่ n" เลขหน้าตัวเลือก และบรรทัดคำแนะนำ (ถูกตัดออกตามการตัดสินใจ) ความสูงของภาพปรับตามความสูงจอ (ราว 345px บน 390×844) ระยะห่างระหว่างส่วน 16px และการ์ดเว้นให้โปร่ง หน้าไม่ต้องแสดงครบในจอเดียว ให้เลื่อนดูได้ การ์ดมี focus ring และ hover โดยความหนาขอบคงที่ จึงไม่ขยับเลย์เอาต์

## หน้าผลลัพธ์ (v3.9)

ข้อความของตัวละครและผลลัพธ์ไม่เปลี่ยน (ทั้งชุดวัยทำงานและนักเรียน / นักศึกษา) ปรับเฉพาะการจัดวาง ลำดับ: ภาพตัวละครของชุดที่เลือกอยู่บนสุด กรอบสูงราว 312px ครอปบนล่าง (เหมือนเดิมของหน้า) แผ่นขาวซ้อนทับขอบล่าง และรูปเลื่อนไปพร้อมหน้าตอน scroll เหมือนหน้าถาม–ตอบ → ป้าย "ผลเช็กใจของคุณ · วันนี้" → ชื่อ → ฉายา → ประเภทเมฆ (ไทย) และชื่อชนิดเมฆทางวิทยาศาสตร์ → ประโยค "นี่คือใจคุณช่วงนี้…" → การ์ด "ภาพรวมความรู้สึก" → การ์ดเด่น "ก้าวเล็กๆ ที่เริ่มได้" พร้อมปุ่ม "เลือกวิธีดูแลใจ" ไปหน้าเลือกวิธีดูแลเดิม → ส่วนพับ "รู้จัก [ชื่อ] ให้มากขึ้น" → ประโยคปิดในกรอบแยก → "แชร์ผลลัพธ์นี้" และ "ดูก้าวต่อไป" → ส่วนท้าย การจับคู่เพื่อนซี้ไม่เปลี่ยน
