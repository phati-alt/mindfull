# Meet Your Cloud: ข้อมูลตัวละคร 4 ตัว

ตัวละครทุกตัวคือ "เพื่อนเมฆที่มาเยือนวันนี้" ไม่ใช่ตัวตนถาวร ข้อความทั้งหมดตรงกับ `prototype/content.js`

## Cumulo (คิวมูโล) — มอนสเตอร์แห่งความพร้อมรับมือ

| หัวข้อ | รายละเอียด |
| --- | --- |
| key ในโค้ด | `storm` |
| ชนิดเมฆ | คิวมูโลนิมบัส | เมฆพายุ |
| รู้จัก | Cumulo มาเยือนในวันที่ใจคุณอยู่ในโหมดเตรียมรับมือตลอดเวลา พลังงานยังมีเต็ม แต่ถูกใช้ไปกับการคิดวนและกังวลล่วงหน้า จนใจไม่ได้พักจริงแม้เลิกงานแล้ว |
| พลังพิเศษ | "เรดาร์จับพายุ" (Readiness) |
| คำอธิบายพลัง | Cumulo เห็นพายุก่อนใครเสมอ งานไหนเสี่ยงพลาด เรื่องไหนอาจบานปลาย Cumulo รู้ก่อนและเตรียมรับมือไว้แล้ว ทีมจึงไว้ใจ แต่บางวันเรดาร์ทำงานหนักจนไม่ยอมปิด แม้ตอนที่ไม่มีพายุจริง |
| จุดเด่น | รับผิดชอบสูง ทีมไว้ใจได้ |
| เมื่อพลังล้น | เรดาร์ไม่ยอมปิด แม้ไม่มีพายุจริง |
| How to ดูแล · ตอนนี้ 20 วิ | หายใจออกให้ยาวกว่าหายใจเข้า 2 รอบ ให้เรดาร์ได้พัก |
| How to ดูแล · คืนนี้ | เขียนเรื่องที่วนในหัวลงกระดาษก่อนนอน |
| How to ดูแล · สัปดาห์นี้ | เลิกงานตรงเวลาสักวัน แล้วปิดแจ้งเตือนแชตงาน |
| Reframe | พายุไม่ได้แปลว่าคุณอ่อนแอ มันแปลว่าคุณกำลังแบกหลายเรื่องที่สำคัญกับคุณ |
| เพื่อนซี้ | Humi: ช่วยเตือนว่าไม่ใช่ทุกเรื่องที่ต้องรับมือวันนี้ |
| รู้ไหม (การ์ดแชร์) | เมฆคิวมูโลนิมบัสก่อตัวสูงได้มากกว่า 10 กิโลเมตร และเป็นเมฆชนิดเดียวที่ทำให้เกิดฟ้าแลบฟ้าร้อง |

## Nimbo (นิมโบ) — มอนสเตอร์แห่งการดูแล

| หัวข้อ | รายละเอียด |
| --- | --- |
| key ในโค้ด | `rain` |
| ชนิดเมฆ | นิมโบสเตรตัส | เมฆฝน |
| รู้จัก | Nimbo มาเยือนในวันที่คุณแบกมานานจนแบตใจใกล้หมด ยังทำหน้าที่ได้ ยังดูแลคนอื่นได้ แต่ข้างในเหนื่อยแบบที่นอนพักอย่างเดียวไม่หาย เพราะต้นเหตุคือภาระที่ยังไม่ได้วางลง |
| พลังพิเศษ | "ร่มใบใหญ่" (Care) |
| คำอธิบายพลัง | Nimbo ไม่เคยปล่อยให้ใครเปียกฝน งานของเพื่อน ปัญหาของทีม Nimbo ช่วยกันไว้หมด ใครอยู่ใกล้ก็รู้สึกปลอดภัย แต่บางวัน Nimbo กางร่มให้ทุกคนจนลืมไปว่าหัวตัวเองก็เปียกอยู่ |
| จุดเด่น | อดทน ใส่ใจ ไม่ทิ้งใคร |
| เมื่อพลังล้น | กางร่มให้ทุกคน จนลืมกางให้ตัวเอง |
| How to ดูแล · ตอนนี้ 20 วิ | พิมพ์ 1 เรื่องที่จะวางลงก่อนในวันนี้ |
| How to ดูแล · คืนนี้ | พักให้จริง 1 ชั่วโมง โดยไม่ทำงานและไม่รู้สึกผิด |
| How to ดูแล · สัปดาห์นี้ | ขอความช่วยเหลือ 1 เรื่องจากคนรอบตัว |
| Reframe | ฝนตกไม่ได้แปลว่าฟ้าพัง มันคือสัญญาณว่าถึงเวลาพัก |
| เพื่อนซี้ | Cumulo: ช่วยกันแบ่งงาน ไม่ต้องแบกคนเดียว |
| รู้ไหม (การ์ดแชร์) | เมฆนิมโบสเตรตัสแผ่กว้างจนบังฟ้าทั้งผืน และให้ฝนตกต่อเนื่องได้หลายชั่วโมง |

## Strato (สตราโต) — มอนสเตอร์แห่งการพักใจ

| หัวข้อ | รายละเอียด |
| --- | --- |
| key ในโค้ด | `fog` |
| ชนิดเมฆ | สเตรตัส | เมฆหมอก |
| รู้จัก | Strato มาเยือนในวันที่คุณไม่ได้เศร้าหรือเครียดชัดเจน แต่ไม่ค่อยรู้สึกอะไร ทุกอย่างดูเฉยๆ ไปหมด บางครั้งนี่คือวิธีที่ใจพักหลังจากแบกมานาน แต่ถ้า Strato อยู่นาน ความเฉยชาก็ควรได้รับการใส่ใจเป็นพิเศษ |
| พลังพิเศษ | "ผ้าห่มหมอก" (Shield) |
| คำอธิบายพลัง | เมื่อทุกอย่างมากเกินไป Strato จะห่อใจคุณไว้ในผ้าห่มหมอก เสียงรอบตัวเบาลง เรื่องหนักๆ ดูไกลออกไป แต่ถ้าห่ออยู่นานเกินไป ก็อาจเริ่มไม่รู้สึกอะไรเลย |
| จุดเด่น | สงบ ไม่ตื่นตูม ปกป้องใจเก่ง |
| เมื่อพลังล้น | ห่อนานจนเริ่มไม่รู้สึกอะไร |
| How to ดูแล · ตอนนี้ 20 วิ | Grounding 3-2-1 กลับมารับรู้สิ่งรอบตัวทีละอย่าง |
| How to ดูแล · คืนนี้ | ทำสิ่งเล็กๆ ที่เคยชอบสัก 10 นาที |
| How to ดูแล · สัปดาห์นี้ | ทักเพื่อนสักคน ชวนคุยหรือกินข้าวด้วยกัน |
| Reframe | หมอกไม่ได้ทำให้ท้องฟ้าหายไป มันแค่บังไว้ชั่วคราว |
| เพื่อนซี้ | Nimbo: ชวนกันพักแบบไม่ต้องอธิบายอะไร |
| รู้ไหม (การ์ดแชร์) | หมอกคือเมฆสเตรตัสที่ลอยต่ำจนแตะพื้น และพอแดดออก หมอกก็ค่อยๆ จางไปเอง |

## Humi (ฮิวมี่) — มอนสเตอร์แห่งความสมดุล

| หัวข้อ | รายละเอียด |
| --- | --- |
| key ในโค้ด | `fluffy` |
| ชนิดเมฆ | คิวมูลัส ฮิวมิลิส | เมฆปุย |
| รู้จัก | Humi มาเยือนในวันที่ฟ้าในใจค่อนข้างเปิด คุณมีแรงพอทำงาน และยังมีที่ว่างให้ตัวเอง สิ่งที่น่าสนใจคืออะไรทำให้คุณเป็นแบบนี้ เพราะนั่นคือสิ่งที่ควรรักษาไว้สำหรับวันที่ฟ้าครึ้ม |
| พลังพิเศษ | "แบตสำรอง" (Recharge) |
| คำอธิบายพลัง | Humi รู้วิธีเติมพลังให้ตัวเอง และมีเหลือพอแบ่งให้คนรอบข้าง วันไหนที่ Humi มาเยือน งานเดินลื่น ใจเบาสบาย แต่บางครั้งก็แบ่งพลังจนลืมสังเกตว่าอะไรทำให้ตัวเองเป็นแบบนี้ |
| จุดเด่น | ยืดหยุ่น ฟื้นตัวเร็ว อยู่ด้วยแล้วสบายใจ |
| เมื่อพลังล้น | แบ่งพลังจนลืมสังเกตว่าอะไรทำให้ตัวเองดี |
| How to ดูแล · ตอนนี้ 20 วิ | จด 1 อย่างที่ทำให้สัปดาห์นี้โอเค |
| How to ดูแล · คืนนี้ | ทำสิ่งที่ช่วยให้โอเคต่อ เช่น นอนให้ตรงเวลา |
| How to ดูแล · สัปดาห์นี้ | เช็กเพื่อนสักคนที่อาจกำลังเจอพายุ |
| Reframe | วันฟ้าใสก็เป็นวันที่ดีที่จะสังเกตว่าอะไรช่วยให้ฟ้าใส |
| เพื่อนซี้ | Strato: แบ่งแสงแดดให้หมอกจางลง |
| รู้ไหม (การ์ดแชร์) | เมฆคิวมูลัส ฮิวมิลิสคือเมฆก้อนเล็กๆ ที่ลอยอยู่ในวันฟ้าใส และเป็นสัญญาณของอากาศดี |

## ตัวละครกลางในหน้าคำถาม

คนหัวเมฆสีขาว สูทกรมท่า เนคไทเทอร์ควอยซ์ ใช้ในภาพประกอบคำถามทุกข้อ ไม่ใช่ตัวไหนในสี่ตัว จึงไม่บอกใบ้ผล
